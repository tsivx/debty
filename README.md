# Долговая книжка 📒

Mobile-first PWA для учёта долгов: «я должен» и «мне должны», платежи частями, прогресс-бары, сроки с подсветкой и история платежей.

**Демо:** https://tsivx.github.io/debty/

## Возможности

- 📊 Сводка по направлениям с прогрессом **по каждой валюте отдельно** (без курсов обмена)
- 💳 Долги: человек / банк / другое — сумма, валюта, описание, крайний срок, контакты (телефон, Telegram, почта — кликабельны)
- 💰 Платежи частями: кнопки 25% / 50% / «Всё», слайдер, дата и заметка
- ⏰ Статусы сроков: просрочен (красный) и «горит срок» ≤ 7 дней (оранжевый)
- 🕐 Общая история платежей + история внутри каждого долга
- 🔍 Поиск, фильтры-вкладки, сортировка
- 🌓 Тема: светлая / тёмная / системная
- 💾 Данные только в localStorage + экспорт/импорт JSON
- 📱 PWA: устанавливается на домашний экран, работает офлайн
- 📱 Mobile-first: нижние табы, полноэкранные формы, на десктопе — модалки

## Технологии

Vite · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · sonner · react-day-picker · vite-plugin-pwa

## Локальный запуск

```bash
npm ci
npm run dev        # http://localhost:5173
```

Полезные команды:

```bash
npm run build      # сборка в dist/ (+ service worker)
npm run preview    # предпросмотр сборки
npm run lint       # oxlint
npm run icons      # перегенерация PNG-иконок из public/icon.svg
```

## Деплой

Пуш в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`): проверка типов и линтера → `npm run build` → публикация `dist/` на GitHub Pages.

## Структура

```
src/
  lib/          # типы, хранилище (localStorage), формат, статусы, демо-данные
  components/
    ui/         # примитивы shadcn/ui
    screens/    # экраны: главная, история, настройки
    *.tsx       # формы, карточки, панель деталей, шапка, табы
public/         # манифест PWA, иконки
scripts/        # генератор иконок, скриншоты
```

## Данные

Всё хранится локально в браузере под ключами `debty:debts:v1` и `debty:settings:v1`. Никуда не отправляется — делайте регулярно экспорт JSON в настройках.
